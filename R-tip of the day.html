An introduction to broom 🧹

What is broom?

  • broom is a package that converts statistical model output into tidy data frames

  • This makes results easier to:

    • visualize
    • combine
    • export

  • Works well with: dplyr, ggplot2 and purrr

broom Functions

The three main functions are:

Function Purpose
tidy() creates tidy coefficient tables
glance() summarizes model performance
augment() adds predictions and residuals

tidy()

model <- lm(lifeExp ~ gdpPercap, data = gapminder)

tidy(model)
# A tibble: 2 × 5

tidy()

tidy(model) |>
  select("term","estimate")|>
  filter(term=="gdpPercap")
# A tibble: 1 × 2
  term      estimate
  <chr>        <dbl>
1 gdpPercap 0.000765
  • Easy to filter and visualize

broom + ggplot2

augment(model) |>
  ggplot(aes(lifeExp, .fitted)) +
  geom_point(alpha = 0.5) +
  geom_abline(slope = 1, 
              intercept = 0,
              color = "red"
  ) +
  labs(
    title = "Actual vs Predicted",
    x = "Actual Life Expectancy",
    y = "Predicted Life Expectancy"
  )

Comparing models

model_log <- lm(lifeExp ~ log(gdpPercap), data = gapminder)
augment(model_log) |>
  ggplot(aes(x = lifeExp, y = .fitted)) +
  geom_point(alpha = 0.5) +
  geom_abline(  slope = 1,  intercept = 0, color = "red",
    linewidth = 1
  ) +
  labs(
    title = "Actual vs Predicted Life Expectancy",
    x = "Actual Life Expectancy",
    y = "Predicted Life Expectancy"
  )

Summary

  • glance() summarizes model performance
  • augment() adds predictions and residuals
